GitHub 트렌딩 첫 진입: 매일 쓰는 에이전트 스킬 꾸러미 tstack

2026-10-26

에이전트 스킬 꾸러미 tstack이 10월 26일 GitHub 트렌딩에 처음 올라왔다.

개발자 Theo가 매일 쓴다는 스킬 모음으로, 끝까지 일을 밀어붙이는 스킬과 세 모델이 합의할 때까지 리뷰를 돌리는 스킬이 들어 있다.

스킬은 AI에게 주는 '일하는 방법 설명서' 같은 것이다.

왜 중요한가: AI에게 뭘 시킬지가 아니라 '어떻게 일하게 할지'가 경쟁력이 됐다는 신호 — 요리법을 공유하듯 일하는 방식을 묶어 파는 시대다.
