코딩 AI에게 로봇 팔을 맡겼더니 신기록 — HexaShell

2026-10-16

HexaFuture 팀이 비전-언어 코딩 에이전트에게 양팔 로봇을 맡기는 얇은 하네스 HexaShell을 발표했다.

에이전트는 명령줄 하나로 로봇을 조종한다. 카메라 3대로 보고, 실패하면 로그를 읽고 스스로 작은 프로그램을 고친다.

42개 RoboDojo 과제에서 성공률 39.7%로 최고 기록. 한계는 '닿는 것' — 밀기는 92.5%인데 정밀 끼우기는 8.3%다.

왜 중요한가: 코딩 AI가 컴퓨터 대신 로봇을 만지는 실험 — 머리(이성)는 되는데 손끝(접촉)이 아직 서툰 아기 같은 상태다.
