코딩 에이전트, 코드는 잘 짜는데 보안은 못 지킨다 — 새 벤치마크 LSCBench

2026-10-14

새 벤치마크 LSC벤치는 코딩 에이전트를 '기능'과 '보안' 두 시험으로 채점한다. 숨겨진 보안 테스트가 실제 공격을 재현한다.

6개 프론티어 에이전트가 기능은 73.6~91.3% 통과했지만, '돌아가면서 안전한' 코드는 최고도 25.1%에 그쳤다.

과제는 일부러 보안을 언급하지 않는다. 실제 사용자처럼 '가져오기 기능 만들어줘'라고만 하기 때문.

왜 중요한가: 겉보기엔 완벽한 집인데 창문 잠금장치가 전부 고장 난 것처럼 — 테스트 초록불이 안전을 보장하지 않는다.
