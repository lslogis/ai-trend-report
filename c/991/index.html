애플, 맥을 직접 조종하는 자체 AI 에이전트 개발 중 (블룸버그 보도)

2026-11-20

애플이 맥을 직접 조종하는 자체 AI 에이전트를 만들고 있다는 보도가 나왔어요. 근거는 애플이 올린 채용 공고예요.

웹 탐색, 앱 넘나들기, 명령 실행, 코드 작성·디버깅까지 혼자 해내는 비서를 그린다고 해요.

아직 초기 단계라 내년 말쯤 나올 수도 있다는 얘기예요. 애플 공식 발표는 아직 없어요.

왜 중요한가: 애플이 남의 비서를 들여놓는 대신, 자기 집 비서를 직접 키우기 시작한 거예요.
