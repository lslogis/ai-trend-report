초당 1068토큰 — 디퓨전 모델이 프론티어 속도 티어에 올랐다 (Inception Mercury 3)

2026-10-19

레드우드 시티의 스타트업 Inception이 10월 19일 'Mercury 3'를 냈습니다. 디퓨전 언어 모델로, 한 글자씩 쓰는 게 아니라 여러 글자를 한꺼번에 다듬어 내는 방식이라 초당 1068토큰이라는 미친 속도가 나옵니다.

속도는 첫째 치고, 실력도 빵빵합니다. 자사 테스트 기준 GPT-6 Luna·Claude Haiku 5.5와 동급 이상인데 4~8배 빠릅니다. 컨텍스트는 100만 토큰, 가격은 출격 기념 반값(입력 백만 토큰당 0.10달러).

Mercury 1(2025년 6월)보다 40배 커졌는데도 속도는 그대로 — "디퓨전도 스케일링된다"는 걸 증명한 셈입니다. API 전용(오픈소스 아님), OpenAI API와 호환돼 갈아타기 쉽습니다.

왜 중요한가: AI 에이전트 시대에 '속도'가 돈이다 — 에이전트는 한 번 일할 때 모델을 수십 번 불러 쓰니, 빠른 모델은 그냥 편의가 아니라 생산력 그 자체. 마치 고속도로 톨게이트가 4차선에서 8차선으로 늘어난 느낌이죠.
