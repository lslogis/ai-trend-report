엔비디아 Nemotron 3.5 Transcribe + Granary v2 — 40개 언어 받아쓰기 오픈 모델

2026-10-28

10월 28일 엔비디아가 말소리를 글로 바꿔주는 오픈 모델 'Nemotron 3.5 Transcribe'를 내놨다.

40개 언어로 받아쓰고, 31개 언어는 영어로 번역하며, 말하는 사람이 최대 8명까지 누구인지도 가려낸다.

1시간짜리 녹음도 한 번에 처리하고, 칩 하나에서 돌아가는 30B 크기다. 음성 자료 'Granary v2'(48개 언어, 46만 시간 분량)도 함께 공개됐다.

왜 중요한가: 회의록이나 병원 기록처럼 말을 글로 옮기는 일이, 이제 남의 서버에 맡기지 않고 내 장비에서도 가능해진다는 뜻이다.
