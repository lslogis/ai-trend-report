토큰마다 일 잘하는 모델에게 일을 나눠주기 — TokenRouter

2026-10-08

LLM 여러 개를 섞어 쓰는 '라우팅'은 보통 질문 단위로 나눴는데, 이건 글자(토큰) 단위로 나눠주는 서빙 시스템을 만들었어요.

토큰 단위로 나누면 속도·품질이 좋아지지만, 기존 서버는 속도가 엇박자가 나서 버벅였어요.

새 시스템은 요청 기준으로 프로그래밍하고 실행은 모델별로 나눠 처리해서, 기존보다 2배~64배 빠른 디코딩 속도를 냈어요.

왜 중요한가: "AI 서비스 요금의 핵심은 '토큰 처리 속도'인데, 인프라를 바꾸는 것만으로 최대 수십 배 효율이 올라가요."
