Obsidian이 만든 Mermaid 렌더러 'Pele' 공개

2026-10-18

메모 앱 Obsidian 팀이 다이어그램 도구 'Pele'를 오픈소스로 냈다. Mermaid 문법을 SVG 그림으로 바꿔준다.

의존성 0개, 번들 230kB — 기존 렌더러의 6분의 1 수준이다. 렌더링은 최대 500배 빠르다고 주장한다.

CSS 변수로 테마를 바꾸면 다시 그리지 않아도 색이 바뀐다. 다크모드 전환이 순식간이다.

왜 중요한가: '그림 하나 그리는데 무거운 도구를 통째로 끌고 올 필요 없다'는 미니멀리즘 — 작은 도구가 큰 도구를 이기는 순간이다.
