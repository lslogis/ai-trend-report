긴 호흡 에이전트 훈련법 — 나무처럼 가지를 치며 배우는 TreeOPSD

2026-10-16

텐센트 훈위안 팀이 긴 작업 에이전트의 강화학습법 TreeOPSD를 발표했다.

매 턴을 나무의 가지로 보고, 여러 갈래를 뻗어본 뒤 성공한 길의 공을 각 턴에 나눠준다.

별도 비평가 모델 없이도 GRPO보다 딥리서치 과제에서 평균 4.97점 올랐다.

왜 중요한가: 장기 프로젝트의 공을 '누가 잘했나'로 나누는 것과 같다 — 마지막에 성공했으면 중간 단계의 잘한 선택도 찾아내 칭찬한다.
