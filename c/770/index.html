Pruna P-H3-Image — 비디오 모델을 뜯어 만든 오픈 이미지 모델

2026-11-03

Pruna AI가 11월 3일 P-H3-Image를 공개했어요. MiniMax-H3 비디오 모델을 이미지 모델로 뜯어고친 오픈웨이트예요.

트랜스포머는 330억 개에서 200억 개로, 텍스트 인코더는 320억 개에서 40억 개로, 확산 단계는 50번에서 8번으로 줄었어요.

ComfyUI 양자화판은 약 20GB, VRAM 21GB 정도로 8메가픽셀 그림을 만들어요.

왜 중요한가: 영화 스튜디오를 사진관으로 다이어트시킨 거예요. 작은 방에도 들어갈 만큼 가벼워졌어요.
