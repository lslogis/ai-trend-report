GPT-6.1 Terra, 출시 당일 AWS Bedrock·GitHub Copilot에도 상륙

2026-10-26

아침에 나온 GPT-6.1 Terra가 같은 날 AWS Bedrock에서도 쓸 수 있게 됐다.

GitHub Copilot에도 같은 날 들어갔다.

이미 OpenAI에서 나온 모델이 클라우드 가게 2곳에 더 입점한 것으로, 새 모델 발표가 아니라 파는 곳이 늘어난 소식이다.

왜 중요한가: 좋은 모델도 파는 곳이 많아야 쓰인다 — 인기 과자가 편의점마다 들어가는 것처럼, 개발자들이 이미 쓰는 도구에 들어간 게 핵심이다.
