AI가 뭘 배웠는지 역추적의 한계 (BehaviorTrace)

2026-10-07

강화학습으로 AI가 새로 배운 행동이 '어떤 학습 데이터 조각'에서 왔는지 역추적할 수 있는지 시험한 연구예요.

의도적으로 심어놓은 행동을 찾아내는 실험으로, 데이터 기여도 주장의 한계를 검증했어요.

학습 데이터 저작권·책임 소재 논의와 연결되는 논문이에요.

왜 중요한가: "AI가 배운 건 누구 덕분인가"를 묻는 연구예요. 학습 데이터 저작권·책임 소재 논쟁과 직결돼요.
