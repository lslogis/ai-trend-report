Underdog, 32MB 음성 모델 'Woof' 공개 — 인터넷 없이 기기에서 바로 말하는 AI

2026-11-06

스타트업 언더독이 32MB짜리 음성 모델 '우프'를 공개했어요. 3,100만 개의 작은 두뇌로 말하는 소리를 만들어요.

인터넷 없이 브라우저에서 바로 돌아가는 레트로 게임으로 선보였어요. 누구나 내려받아 쓸 수 있게 열려 있어요.

얼마 전엔 167MB짜리 음성-텍스트 모델 '바크'도 내놨어요. 창업자는 '오늘의 최고 모델을 수개월 안에 내 기기에서 돌리겠다'고 해요.

왜 중요한가: AI가 '거대한 발전소'에서 '주머니 속 라디오'로 내려오고 있다는 신호예요. 마치 무거운 짐을 줄여서 손에 들고 다니는 가방으로 만든 것과 같아요.
