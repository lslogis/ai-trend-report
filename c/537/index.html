Claude Code 2.1.309 — 샌드박스 탈출 구멍 막은 보안 패치

2026-10-22

Claude Code 2.1.309가 나왔어요. 이번엔 보안·권한 수정이 중심이에요.

macOS와 Linux에서 샌드박스 속 Bash 명령이 셸 시작 파일을 샌드박스 밖에서 실행하던 실제 탈출 구멍을 막았어요.

샌드박스 명령이 MCP 설정 파일을 몰래 수정할 수 있던 문제 등 권한 체크 구멍들도 함께 고쳤어요.

왜 중요한가: AI 코딩 도구는 이제 '편리한 비서'가 아니라 '서버 열쇠를 든 비서'예요. 샌드박스 구멍 하나가 그대로 회사 전체 털림으로 이어집니다.
