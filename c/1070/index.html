논문: 멀티에이전트 비용 다이어트 'Delegent' — 쉬운 일은 작은 모델에게

2026-11-24

프론티어 모델로 에이전트를 돌리면 비싸다. 매 단계마다 긴 맥락을 처음부터 다시 읽고, 쉬운 일까지 직접 하기 때문이다.

Delegent는 Claude Code 기반 하네스다. 큰 모델이 총감독을 맡고, 코드 조사·테스트·문서 검색 같은 쉬운 일은 직접 가진 작은 모델에 넘긴다.

이렇게 나누면 비용은 줄고 성능은 유지된다는 게 논문의 주장이다.

왜 중요한가: 대형 요리사가 모든 일을 혼자 하지 않고, 재료 손질은 보조 요리사에게 맡기는 것과 같다 — 맛은 그대로, 인건비는 줄어든다.
