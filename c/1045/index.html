OpenAI·Cisco, 오픈소스 보안 런타임 'Shirudo' 공개 — 재시작 없이 실행 중인 Linux를 지킨다

2026-11-23

OpenAI와 Cisco가 11월 23일 오픈소스 보안 도구 'Shirudo'(일본어로 '방패')를 공개했어요.

리눅스 시스템이 돌아가는 동안, 재시작 없이 임시 보안 방패를 씌워 취약점 공격을 막아요. 정식 패치가 나올 때까지 시간을 벌어주는 거예요.

방패는 암호화 서명을 받고 TPM 칩으로 검증해요. 같은 날 공개된 GPT-6 Cyber는 한 번의 실행으로 루트 권한 관련 리눅스 커널 버그 948건을 검증하고 패치 초안을 만들었다고 해요.

왜 중요한가: 컴퓨터에 구멍이 뚫렸는데 정식 수리는 아직 멀었을 때, 일단 방수 테이프로 구멍을 막아두는 거예요. 문을 닫지 않고도 막을 수 있으니, 가게 영업을 멈추지 않고도 안전해져요.
