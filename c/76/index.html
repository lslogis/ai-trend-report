GitHub 트렌딩 1위 'REA' — 앱을 뜯어보는 AI 코디네이터, 일주일 만에 스타 18만

2026-10-14

REA(Reverse Engineer Anything)가 일주일 만에 스타 18만 개를 받으며 GitHub 트렌딩 1위에 올랐다.

AI 코딩 에이전트에 꽂는 MCP 서버다. 에이전트가 질문하면 REA가 실제 분석 도구(기드라·IDA·닷넷 리더)를 돌려 근거와 함께 답을 돌려준다.

네이티브 코드는 고전 디컴파일러로 뜯고, AI가 뒤죽박죽 출력을 읽어 깨끗한 코드로 다시 써준다.

왜 중요한가: 탐정에게 돋보기와 감식반을 쥐여주는 셈 — 에이전트가 묻고, 도구가 뜯고, AI가 설명한다.
