로봇이 스스로 코드로 진화한다 — Embodied Turing Machines

2026-10-08

보통 로봇은 매 순간 AI 모델에게 "지금 뭘 할까?"를 묻는데, 이 논문은 "로봇 상태를 코드로 정확히 표현하면 판단도 코드로 다 할 수 있다"고 주장했어요.

카메라·관절 센서로 상태를 재고, 코드가 직접 판단하는 방식(COAP)이라 빠르고 싸고, 실패해도 유연하게 복구돼요.

새 일을 배우면 코드 라이브러리에 누적돼서 능력이 쌓이고, 코딩 에이전트가 이걸 자동으로 발전시키는 '자기 개선 루프'까지 돌렸어요. 42개 양팔 작업에서 성공률 70.24%를 찍었어요.

왜 중요한가: "매번 거대 AI를 부르지 않고도 로봇이 일할 수 있게 되면, 로봇 운영비가 확 떨어져요 — '모델 없는 로봇'의 가능성."
