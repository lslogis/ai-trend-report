논문: 하나의 정책으로 백만 가지 로봇 몸을 — 몸 구조를 읽는 OmniAct

2026-11-24

로봇은 팔 길이도, 관절 개수도 제각각이라 하나의 AI로 조종하기 어려웠어요.

OmniAct는 각 로봇의 관절 구조를 그래프로 읽고, 그 몸에 맞는 움직임을 만들어요.

덕분에 하나의 정책으로 자유도가 다른 여러 로봇을 조종할 수 있어요.

왜 중요한가: 로봇마다 몸이 다른데도 하나의 운전면허로 모든 차를 운전하는 것과 같아요. 몸을 먼저 읽고 운전을 맞추는 거죠.

출처: 로봇마다 다른 몸, 하나의 뇌로 조종한다
