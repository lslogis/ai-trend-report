논문 ReTrace — 도구 쓰는 에이전트를 '계획 없는' 빠른 워크플로로 증류

2026-11-10

논문 '리트레이스'는 도구 쓰는 AI 에이전트를 더 빠르고 싸게 만드는 방법을 제안했어요.

지금 에이전트는 일할 때마다 '다음엔 뭘 할까' 계획을 새로 짜느라 시간과 돈이 많이 들어요.

리트레이스는 잘된 행동을 '계획 없이 바로 실행하는' 워크플로로 바꿔 담는 방법이에요. 매번 고민하지 않고 몸에 밴 순서대로 일하는 거예요.

왜 중요한가: AI에게도 '요리 레시피'처럼 몸에 밴 순서를 만들어주면, 매번 처음부터 생각하지 않아도 된다는 아이디어예요. 마치 자전거 타는 법을 몸이 기억하는 것과 같아요.
