2026-10-17

딥시크가 10월 17일 V4.1-Flash-1017을 내놨어요. 가중치는 MIT 라이선스로 공개됐고, API 이름(deepseek-flash)은 그대로라 기존 사용자는 자동으로 새 버전을 쓰게 돼요.

코딩 벤치마크 DeepSWE에서 77.0점을 찍어 Opus 5(74.0)와 GPT-5.6 Sol(73.0)을 앞질렀어요. 출력은 짧아지고 속도는 빨라졌어요.

가격은 그대로(입력 백만 토큰당 $0.15)라 코딩 과제 하나당 몇백 원 수준이에요. 검색·가져오기(Search & Fetch) API도 처음 외부에 열었어요.

왜 중요한가: 분식집에서 김밥 한 줄 값으로 고급 코스 요리를 내주는 격이에요. 맛(성능)은 셰프급인데 값은 분식집인 거죠.
