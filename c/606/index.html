OpenAI, GPT-6.1 Terra 출시 — 가격 절반, 컴퓨터를 직접 조작하는 모델

2026-10-26

OpenAI가 10월 26일 새 모델 GPT-6.1 Terra를 내놨어요.

API 가격이 입력 100만 토큰당 1달러, 출력 5달러로 이전 모델의 절반이에요.

화면을 보고 클릭하고 입력하는 '컴퓨터 조작'에 특화됐고, ChatGPT Work·Codex·API에서 쓸 수 있어요.

왜 중요한가: 배달 오토바이 값이 절반이 됐는데 짐은 똑같이 싣는 격 — 사무실 잡일을 AI에 맡기는 게 훨씬 더 많은 사람에게 말이 되는 순간이에요.
