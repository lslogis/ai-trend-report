OpenAI, 3.5시간 동안 멈췄다 — 인증 DB 복제본 2개가 동시에 고장

2026-11-21

11월 21일 오후, 챗GPT와 API 요청 4개 중 3개가 실패하는 장애가 3시간 30분 이어졌다.

원인은 평범한 데이터베이스 정기 점검 — 인증을 맡은 Postgres 복제본 2개가 동시에 멈췄다.

대화·로그인·검색·파일·음성까지 챗GPT 기능 대부분과 API 10여 종이 함께 영향을 받았다.

왜 중요한가: 집 열쇠를 맡긴 경비실 문이 두 개 다 잠겨버린 셈 — 열쇠는 있는데 아무도 문을 열어줄 수 없었다.
