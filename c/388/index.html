애플, 앱스토어에서 'AI 누디파이' 앱 퇴출 규정 강화

2026-10-16

애플이 10월 16일 앱스토어 심사 지침을 바꿔, AI로 만든 비동의 성적 이미지(딥페이크) 방지를 앱에 의무화했어요.

심사 때는 기능을 숨겼다가 승인 후 켜는 '바꿔치기' 앱도 새 규정(2.5.19)으로 정조준했어요.

xAI 그록이 미성년자 딥페이크에 악용된 뒤 샌프란시스코 시 검사가 애플에 삭제 명령을 내린 게 직접 계기가 됐어요.

왜 중요한가: 놀이터 입구에 '위험한 장난감 반입 금지' 팻말을 더 크고 구체적으로 다시 붙인 거예요. AI 장난감이 위험해지자 규칙도 같이 자란 셈이죠.
