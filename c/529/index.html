데이트레이딩을 가르치는 Claude 스킬 11종 세트

2026-10-20

차트 스캐너→뉴스 추적→진입 타이머→청산 플래너→타임머신(1만 회 시뮬레이션)→리스크 관리까지 이어지는 11개의 Claude Code 스킬 묶음이다.

MIT 라이선스에 Yahoo Finance·SEC EDGAR 같은 무료 공개 데이터만 사용하고, 기본값은 모의투자(페이퍼 트레이딩)다.

스타 685를 기록하며 트레이딩·퀀트 관심층에서 빠르게 퍼지고 있다.

왜 중요한가: 주식 공부용 '모의고사 문제집'을 AI가 자동으로 풀어주는 것과 같다. 진짜 돈이 아니라 연습장으로 쓰는 도구라는 점이 핵심이다.
