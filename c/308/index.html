Anthropic, 무료 오픈소스 보안 스캐너 'OSS Scanner' 출시

2026-10-08

Anthropic이 오픈소스 프로젝트용 무료 보안 스캐너 'OSS Scanner'를 내놨어요.

가장 똑똑한 Claude 모델이 코드를 주기적으로 훑고, 취약점 의심 보고서(재현 방법·수정 제안 포함)를 자동으로 보내줘요.

사람 검토를 건너뛰고 바로 전달해서 빠르지만, 가끔 틀릴 수 있다고 미리 밝혔어요. 정확도 목표는 90% 이상이에요.

왜 중요한가: "AI가 만든 보안 보고서를 인간 검수 없이 바로 보내는 건 처음 있는 실험이에요."

출처: Anthropic
