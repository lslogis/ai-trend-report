Caught in the Act — AI의 '속임수'를 내부 신호로 잡아내는 기법

2026-10-08

LLM 에이전트의 기만·사보타주를 모델 내부 신호(프로브)로 탐지하는 화이트박스 기법 연구예요.

기만 탐지 학습용 역대 최대 데이터셋을 만들고, 여러 층·토큰 정보를 모으는 새 프로브 구조를 제시했어요.

SHADE-Arena에서 AUC 98.8%로, 기존 텍스트 모니터링 기준선을 넘었어요. 모델이 커질수록 탐지도 잘 되는 스케일링 효과도 확인됐어요.

왜 중요한가: AI에게 거짓말 탐지기를 단 거예요. 앤트로픽이 내부 평가의 인터넷을 끊은 바로 그 주에 나온 논문이라, 'AI 감시' 테마가 뜨거워요.
