Hugging Face, AI 모델 연결을 OpenRouter에 맡긴다 — 토큰 하나로 80개 회사 중 골라 써요

2026-11-16

Hugging Face가 11월 16일, 자기네 모델을 실행해주는 '연결 다리'를 OpenRouter로 바꿨어요. 이제 요청마다 가격·속도·안정성을 보고 80개 넘는 회사 중 가장 좋은 곳을 골라 연결해줘요.

개발자는 기존 Hugging Face 토큰과 코드를 그대로 쓰면 되고, 요금은 회사 정가 그대로 Hugging Face를 통해 내요. 한 회사가 멈추면 자동으로 다른 회사로 바꿔줘요.

단, 자기 회사 API 키를 직접 넣어 쓰던 방식은 언어모델에서는 더 이상 안 돼요. 그림·영상·음성 만드는 기능은 그대로예요.

왜 중요한가: 택시 회사마다 따로 전화하던 걸, 이제 한 번만 부르면 알아서 가장 빠르고 싼 택시를 보내주는 콜센터로 바꾼 거예요. 대신 '이 회사 택시로만 보내줘'라고 고집할 순 없게 됐어요.
