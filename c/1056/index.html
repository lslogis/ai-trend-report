논문: 멀티모달 검색 에이전트, 도구를 스스로 만든다 — '툴스미스'

2026-11-23

그림·글·실시간 검색을 오가며 답하는 AI는, 사람이 미리 만들어 준 도구만 쓸 수 있었어요.

새로운 질문이나 자료가 나오면 도구가 낡아 버리고, 사람은 도구를 다시 만들어야 했어요.

'툴스미스'는 에이전트가 필요할 때 도구를 스스로 만들어 쓰게 하는 틀이에요.

왜 중요한가: 요리사가 칼이 무뎌질 때마다 대장간에 맡기지 않고, 필요할 때 직접 칼을 만드는 거예요. 도구를 만드는 AI가 되면 새 일에도 바로 적응해요.

출처: 검색 도구가 낡으면, 에이전트가 새 도구를 직접 만든다
