거대 n-gram 표를 4비트로 다이어트 — 메모리 75% 절감

2026-10-22

최근 오픈 모델들이 성능 향상용으로 쓰는 n-gram 임베딩 테이블(DeepSeek-V4.1-Flash는 Engram에 1960억 파라미터 할당)의 메모리 비용을 4비트 양자화로 75% 절감하는 기법을 제안했다.

검증 손실 개선분의 99% 이상을 유지하면서 테이블 메모리를 줄였다.

DeepSeek-V4.1-Flash와 Qwen3.8-Flash-Next 실측에서도 테이블 메모리 47~55% 절감, perplexity 증가 1.2% 미만, 다운스트림 성능은 대체로 유지됐다.

왜 중요한가: 백과사전 전집을 포켓북으로 줄였는데 내용이 거의 그대로인 것과 같다. 큰 모델을 '가볍게' 만드는 지름길이 하나 더 늘었다.
