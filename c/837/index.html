코딩 AI, 실제 업무는 4건 중 1건만 끝까지 — 최고 모델도 완수율 26.4%

2026-11-09

알리바바·대학 연구진이 실제 코딩 세션 2만 6천 건에서 뽑은 웹앱 변경 요청 273건으로 새 시험 'Co-Design Bench'를 만들었다.

최고 모델 GPT-6 Astra도 요구사항을 평균 69.9%는 맞췄지만, 요청을 끝까지 완전히 마친 건 26.4%에 그쳤다.

이 논문은 10월 26일에 나왔는데, 11월 9일 보도가 되면서 다시 주목받았다. 기존 시험은 99% 이상 포화라 실제 실력을 재지 못한다는 지적이다.

왜 중요한가: 숙제를 70%까지는 척척 해내는데 마지막 마무리를 안 해서 결국 사람이 다시 손대야 하는, 똑똑한데 마무리가 약한 조수 같은 수준이다.
