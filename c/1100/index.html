코딩 앱을 통째로 갈아엎었다 — OpenCode 'Rune', 일렉트론 없이 Rust로 다시 쓰다

2026-11-27

OpenCode가 데스크톱 앱을 처음부터 다시 만든 'Rune' 조기 버전을 공개했다.

무거운 일렉트론 대신 Rust로 만든 자체 프레임워크로 만들었는데, 회사는 기존 앱보다 10~100배 빠르고 가볍다고 한다.

앱을 창 없이 실행해 화면을 사진으로 찍고 UI 구조를 뽑아낼 수 있어, 코딩 에이전트가 자기가 만든 화면을 스스로 확인할 수 있다.

왜 중요한가: 코딩 에이전트는 지금까지 '눈 감고' 앱을 만들었다. 자기가 짠 화면을 직접 볼 수 있게 되니, 틀린 버튼을 스스로 고칠 수 있는 셈이다. 안경을 처음 쓴 것과 같다.
