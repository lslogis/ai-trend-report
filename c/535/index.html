Claude가 123개 오픈소스 라이브러리를 '절대 안 터지게' 수학으로 증명

2026-10-22

앤트로픽의 Frontier Red Team과 스타트업 Theorem이 Claude를 시켜 구글 OSS-Fuzz의 123개 오픈소스 라이브러리를 수학적으로 검증했어요.

239개 테스트 진입점에 대해 '64MB 이하 어떤 입력이 와도 메모리 오류 없이 정상 종료된다'는 걸 컴퓨터가 한 줄씩 체크하는 증명으로 만들었어요. 증명문이 무려 약 1억 8천만 줄.

증명을 쓰다 보니 무작위 입력 테스트(퍼징)가 수년간 못 찾은 버그 수백 개가 드러났고, Claude가 직접 고친 뒤 고친 코드도 다시 증명했어요.

왜 중요한가: 소프트웨어 검증이 '운 좋으면 버그를 잡는 낚시'에서 '절대 안 터진다는 보증서'로 바뀌고 있어요. 전문가가 20년 걸리던 일을 AI가 몇 주 만에 한 거예요.
