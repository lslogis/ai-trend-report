Block, Dessa 공개 — 사람 말소리만으로 배운 '듣고 말하기 동시' 음성 모델

2026-10-23

잭 도시의 Block이 사람 말소리만으로 처음부터 학습한 음성 모델 Dessa를 공개했다.

글자로 바꾸는 단계를 거치지 않아 감정·비꼬기·웃음·한숨 같은 말의 결이 그대로 남고, 끼어들기 타이밍도 대화에서 배웠다고 한다.

아직 일반 공개는 아니고 소수 안전 연구자에게만 조기 접근을 주며, 파라미터 수나 공식 벤치는 공개되지 않았다.

왜 중요한가: 통역사를 거치지 않고 두 사람이 직접 귓속말로 대화하는 것과 같다.
