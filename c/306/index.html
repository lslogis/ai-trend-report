JetBrains, 코딩 에이전트용 오픈 모델 'Mellum2.1' 공개

2026-10-08

JetBrains가 코딩 에이전트용 오픈 모델 Mellum2.1을 공개했어요.

120억 파라미터인데 실제로 일할 땐 25억만 켜지는 절약형 구조라 내 컴퓨터에서도 돌아가요. 라이선스는 Apache 2.0이에요.

수백만 개의 가상 코딩 환경에서 강화학습을 돌려, 저장소를 직접 뒤지고 파일을 고치고 스스로 검증까지 할 수 있게 됐어요.

왜 중요한가: "코딩 AI가 클라우드 구독이 아니라 '내 컴퓨터 안의 작은 일꾼'이 되는 흐름이에요."

출처: JetBrains
