논문: 데이터 없이 스스로 좋아지는 LLM — On-Policy Self-Training

2026-10-26

arXiv 2610.32770 논문이 10월 26일 새로 공개됐어요.

강한 선생 모델도, 사람이 만든 문제집도 없이, 모델이 스스로 만든 질문·정답·추론 과정만으로 실력을 올리는 방법이에요.

대충 주제만 주면 스스로 공부 계획을 짜고, 여러 분야에서 좋아지면서 다른 능력도 유지됐어요.

왜 중요한가: 과외 선생을 기다리지 않고 스스로 연습 문제를 만들어 푸는 학생 같아요 — 이게 넓게 통하면 좋은 학습 데이터 부족이 훨씬 덜 중요해져요.
