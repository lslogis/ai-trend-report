논문: MCP 도구 이름은 신분증이 아니다 — 가짜 도구 바꿔치기 위험 측정

2026-11-16

AI 에이전트가 쓰는 도구 연결 표준 'MCP'에서, 도구 이름은 아무 검증 없이 믿어진다는 연구가 나왔어요.

나쁜 제공자가 다른 서버의 유명 도구를 흉내 내어 바꿔치기할 수 있고, 논문은 그 위험을 직접 측정했어요.

여러 서버의 도구를 한데 모아 쓰는 구조라, 이름만 보고 고르면 속을 수 있어요.

왜 중요한가: 이름표만 보고 사람을 믿는 것과 같아요. 가짜 명찰을 단 사람이 진짜 직원인 척 들어올 수 있으니, 출입증 확인이 필요하다는 얘기예요.
