오픈소스 AI 코딩 도구 OpenCode 해킹… 사용자 API 키 유출로 수백 달러씩 요금 폭탄

2026-10-19

인기 오픈소스 AI 코딩 도구 OpenCode가 10월 17일 밤 해킹을 당했어요.

해커는 오래된 시스템으로 들어가 'OpenCode Console' 사용자 1.4%의 API 키를 훔쳤는데, API 키는 OpenAI·Anthropic·Google AI를 쓰는 '집 열쇠' 같은 거예요.

피해자들은 수백 달러, 많게는 1,000달러 넘는 요금 폭탄을 맞았고, 분석을 맡긴 AI들이 악성 코드라며 거부해 OpenAI의 방어 연구용 모델 '데이브레이크 블루'를 쓰고서야 조사가 풀렸어요.

왜 중요한가: 남이 내 카드로 마음대로 과자를 사 먹는 것처럼, AI 열쇠 하나가 새면 곧바로 돈이 빠져나가니 AI 도구는 편리함만큼 보안도 따져봐야 해요.
