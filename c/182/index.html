스스로 진화하는 AI 연구팀, 공식 코드 공개 — SakanaAI/mass

2026-10-12

Sakana AI의 MASS(재귀적 자기개선) 공식 구현이 10월 12일 블로그·코드 함께 공개됐어요.

하나의 27B 모델이 과제 해결·워크플로 최적화·평가 3역을 맡아 팀의 집단 지성을 학습 신호로 증류해요.

'스스로 똑똑해지는 AI'예요. 논문은 10월 8일 제출이라 이번 회차에선 공식 코드 공개를 항목으로 다뤄요.

왜 중요한가: 스스로 공부법을 개선하는 학생이에요. 문제를 푸는 게 아니라 '푸는 방법'을 업그레이드하는 거죠.
