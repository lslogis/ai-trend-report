Soket AI LOOP — 며칠씩 안 쉬고 도는 오픈소스 에이전트 하네스

2026-10-07

인도 정부 IndiaAI Mission에 선정된 Soket AI가 10/7 발표한 Rust 기반 오픈소스 하네스예요.

"며칠~몇 주씩 멈추지 않고 돌아가는 에이전트"용으로, 8개 워커 기준 Claude Code보다 RAM 7.7배·CPU 17배 적게 쓴다고 주장해요.

어떤 모델이든 base URL만 바꾸면 연결 가능해요.

왜 중요한가: "잠 안 자고 일하는 AI 직원의 숙소"예요. 장기 실행 에이전트의 인프라 경쟁이 시작됐어요.
