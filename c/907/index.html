OpenAI Codex CLI 0.168.0·0.169.0 — 하루에 두 번 업데이트, 옆 채팅·음성 메모·모델 선택

2026-11-13

OpenAI의 코딩 도구 Codex CLI가 11월 13일 하루에 두 번이나 업데이트됐다. 0.168.0과 0.169.0이다.

이제 메인 채팅 옆에 사이드 대화 창을 띄워놓고, 음성 녹음을 첨부하고, 쓸 모델 제공자를 직접 고를 수 있다.

움직이는 GIF 만들기, 과거 작업 검색, 안심할 수 없는 폴더에서의 동작 변경도 들어갔다.

왜 중요한가: 코딩 도우미 책상 옆에 메모장을 하나 더 펼치고 음성 메모도 붙일 수 있게 된 셈 — 책상이 점점 넓어진다.
