스텔스 스타트업 Elorian, '이미지로 추론하는' 비주얼 모델 Glimpse 공개

2026-10-16

5500만 달러 시드를 유치한 스텔스 스타트업 Elorian이 첫 AI 모델 'Glimpse'를 연구 프리뷰로 공개했어요.

핵심은 '이미지에 대해' 생각하는 게 아니라 '이미지와 함께' 생각하는 것 — 추론 중간에 이미지를 다시 들여다본대요.

과학 차트 추론에서 GPT-6 Astra를 앞섰다고 주장해 화제예요.

왜 중요한가: 그림을 '보고' 푸는 것과 '읽고' 푸는 건 천지 차이예요. 마치 수학 문제를 눈으로 다시 확인하며 풀듯, AI가 그림을 자꾸 들여다보며 생각하면 실수가 줄어들어요.
