코딩 에이전트 OpenCode 털렸다 — 해커가 노린 건 데이터가 아니라 'AI 사용료'

2026-10-17

인기 코딩 에이전트 OpenCode의 구형 콘솔 시스템이 해킹돼, 사용자들의 OpenAI·앤트로픽·구글 API 키가 노출됐어요(콘솔 사용자의 약 1.4%).

해커들은 데이터를 훔친 게 아니라, 남의 API 키로 비싼 AI 모델을 공짜로 돌린 거예요. 피해자들은 수백 달러짜리 요금 폭탄을 맞았어요.

OpenCode 측은 이를 '대규모 증류(distillation) 공격'이라 불렀고, 앤트로픽은 노출된 Claude 키를 폐기했어요.

왜 중요한가: 금고털이가 아니라 '남의 전기 카드로 게임방을 공짜로 돌린' 사건이에요. AI 시대 해킹의 목표물이 데이터에서 '연산 사용권'으로 바뀌고 있다는 신호예요.
