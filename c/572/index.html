Graphify — 코드베이스를 지식 그래프로 바꿔 에이전트가 '지도 보고' 일하게

2026-10-24

Graphify는 코드·문서·SQL 스키마·PDF를 질의 가능한 지식 그래프로 바꿔, 에이전트가 파일을 일일이 읽는 대신 그래프를 탐색하게 한다.

코드는 LLM 없이 tree-sitter로 로컬에서 파싱하고, 간선마다 EXTRACTED·INFERRED·AMBIGUOUS 태그를 달아 추측과 사실을 구분한다.

'/graphify .'를 실행하면 graph.html·GRAPH_REPORT.md·graph.json이 생기고, Claude Code·Cursor·Codex·Gemini CLI에서 동작한다. GitHub 트렌딩에서 하루 만에 1,092개의 스타를 얻었다.

왜 중요한가: 도시를 배우라며 골목마다 다 걸어보게 하는 대신 지하철 노선도를 쥐여주는 것과 같다.
