[국내] 중국 AI 도구 '아르텍스', 한국 금융권 해킹 악용 논란에 공개 개발 중단

2026-10-10

한국 금융권 연쇄 해킹에 쓰인 중국산 AI 침투 테스트 도구 '아르텍스(ARTEX)'가 공개 개발을 중단해요. 개발자 '오텀-27'이 10월 8일 깃허브에 '악용을 고려해 비공개 소스로 전환한다'고 밝혔어요.

아르텍스는 LLM을 연결해 AI 에이전트가 공격 대상을 분석하고 침투 경로를 계획하며 보안 도구를 실행하는 자율형 침투 테스트 프로그램이에요. 본래는 보안 점검용이에요.

깃허브 페이지는 사라졌지만, 이미 배포된 프로그램까지 회수할 순 없어서 개발 중단만으로 공격을 막긴 어렵다는 지적이 나와요. 크라우드스트라이크는 공격자가 아르텍스와 LLM을 함께 썼다고 분석했어요.

왜 중요한가: 칼을 만든 사람이 '우리 칼로 사고가 났으니 공장에 자물쇠를 채운다'고 한 거예요. 하지만 이미 팔린 칼은 회수가 안 되니, 보안 업계의 숙제는 고스란히 남았어요.
