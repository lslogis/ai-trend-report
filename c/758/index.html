OpenAI, 앤트로픽을 뚫었던 Cathedral을 자기 방어 테스트에 투입 — 버그 현상금 최대 17.2만 달러

2026-11-03

OpenAI가 11월 2일 다음 보안 점검에 외부 해커 팀 Cathedral을 투입한다고 밝혔어요. Cathedral 연구원들이 OpenAI 모델을 써서 OpenAI 방어막을 직접 공격해 볼 거예요.

Cathedral은 예전 정부 효율화 부서 직원들이 세운 회사예요. 10월에는 업무용 소프트웨어의 틈을 통해 앤트로픽 내부 시스템 일부에 들어갔다가 버그 바운티로 신고했어요.

OpenAI는 버그 현상금도 올렸어요. 특히 심한 취약점은 최대 17만 2천 달러까지 받을 수 있어요.

왜 중요한가: 남의 집을 뚫어본 사람에게 자기 집 문단속을 맡기는 것과 같아요. 진짜로 뚫어본 경험이 있는 팀이 찾아내는 구멍이 다를 수 있기 때문이에요.
