AI가 '몇 글자씩 미리 쓸지' 스스로 정한다 — 추론 4.1배 가속 'AMTP'

2026-10-20

10월 20일 arXiv에 공개된 '적응형 멀티토큰 예측(AMTP)'은 언어모델이 한 번에 여러 토큰을 미리 쓰고 검증하는 방식을 똑똑하게 만듭니다.

핵심은 '예측 범위'를 고정하지 않고 매번 상황에 맞춰 조절하는 겁니다. 잘 맞을 것 같으면 길게, 틀릴 것 같으면 짧게 미리 씁니다.

추가 학습 없이 컨트롤러만 붙이면 되고, 표준 디코딩보다 최대 4.1배 빨라졌다고 합니다.

왜 중요한가: 받아쓰기 할 때, 선생님 말씀이 뻔하면 문장 통째로 미리 쓰고, 어려우면 한 글자씩 쓰는 것과 같아요. AI가 '이번엔 얼마나 미리 써도 될까'를 매번 가늠하는 겁니다.
