Pika H3 Flex — 50단계를 6단계로 줄인 오픈웨이트 영상 모델

2026-10-29

Pika가 10월 29일 영상 생성 모델 H3 Flex를 오픈웨이트로 내놨다.

원래 50번에 걸쳐 그리던 과정을 6번으로 줄였다. 짧은 영상을 훨씬 빨리 뽑을 수 있다.

5~15초, 768p 영상에 소리까지 같이 만들고, 사진·영상·소리 참조를 최대 12개까지 넣을 수 있다.

왜 중요한가: 영상 만드는 과정을 '천천히 정성껏 그리기'에서 '밑그림만으로 빠르게 그리기'로 바꾼 셈이다. 영상 제작 문턱이 또 낮아졌다.
