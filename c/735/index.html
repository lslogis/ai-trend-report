OpenAI, 12월부터 ChatGPT와 Codex 사용량을 하나의 토큰 통장으로 합친다

2026-11-02

OpenAI가 11월 2일 이용자에게 메일을 보냈어요. 12월부터 플러스·프로·비즈니스 요금제는 ChatGPT와 Codex 사용량을 하나의 토큰 통장에서 함께 차감해요.

예전처럼 채팅 따로, 코딩 따로 예산이 있는 게 아니에요. 무거운 코딩 작업을 많이 하면 채팅 예산도 같이 줄어들어요.

가벼운 '인스턴트' 채팅은 통장에서 안 빠져요. 남은 양과 초기화 시간은 설정의 사용량 페이지에서 한 번에 볼 수 있어요. 다만 요금제별 토큰 양은 아직 공개되지 않았어요.

왜 중요한가: 밥값 통장과 간식 통장을 하나로 합치는 거예요. 한쪽을 펑펑 쓰면 다른 쪽 쓸 돈도 같이 줄어드니, 예산을 나눠 쓰는 습관이 필요해져요.
