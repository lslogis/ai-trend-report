퍼플렉시티 타임머신 — 과거 날짜의 인터넷으로 검색한다

2026-11-25

에이전트에게 과거 문제를 풀게 하면, 지금 인터넷에서 답을 미리 보고 베끼는 문제가 생긴다. 시험 답안지를 미리 본 셈이다.

퍼플렉시티가 '타임머신'을 내놨다. 날짜를 정하면 그날 이전의 웹 사본만으로 검색하고 읽는다. 365일까지 거슬러 올라간다.

예측 능력을 공정하게 시험하고, 벤치마크 점수를 재현 가능하게 만드는 게 주된 쓰임새다. 추가 요금은 없고 기존 API 가격 그대로다.

왜 중요한가: AI 시험의 공정성은 '문제를 잘 내는 것'이 아니라 '답을 못 보게 하는 것'에서 온다 — 인터넷에 시간 잠금장치를 단 셈이다.
