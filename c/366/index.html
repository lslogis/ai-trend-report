로봇 데이터가 말을 알아듣는다 — Voxel51 3.0 공개

2026-10-15

로봇·피지컬 AI 팀용 데이터 플랫폼 Voxel51이 3.0을 내놨다.

이제 데이터셋을 텍스트 설명이나 '의미'로 검색할 수 있고, 카메라·3D·센서 화면을 동기화해 한눈에 본다.

AI 에이전트가 데이터 찾기→라벨링→평가를 반복 가능한 작업 흐름으로 만들어준다. MCP 도구 45개, 오픈소스 스킬 18개 포함.

왜 중요한가: 로봇 AI 만들 때 시간의 절반 이상을 잡아먹던 데이터 손질 일을 AI 에이전트가 대신 맡아준다 — 로봇의 '집안일'을 맡기는 느낌.
