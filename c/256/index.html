게임으로 AI 실력을 재다 — AAArena, 12개 대결 게임 벤치마크

2026-10-08

AI 에이전트가 대결 게임에서 경험을 쌓아 전략을 스스로 고쳐나가는 능력을 재는 새 시험지 'AAArena'예요. 실제 대결 게임 12종과 인간이 짠 게임 프로그램 1,920개가 들어있어요.

Opus 5.5 + Claude Code 조합이 12개 중 6개에서 금메달을 땄어요. 하지만 나머지 6개 인간 리그에서는 어떤 AI도 1등을 못 했대요.

규칙이 복잡한 게임일수록 AI가 약했고, 상대 고르기·빽빽한 피드백·다른 선수의 리플레이 보기가 실력 향상에 도움이 됐대요.

왜 중요한가: AI에게 바둑 하나만 시킨 게 아니라 12종 격투기 리그를 연 거예요. '경험으로 배우는 AI'의 현주소를 보여주는 성적표예요.
