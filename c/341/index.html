코딩 어시스턴트 하나를 '에이전트 100마리 무리'로 — 오픈소스 ruflo

2026-10-17

GitHub 트렌딩에 오른 오픈소스 '메타 하네스' ruflo예요. 코딩 어시스턴트 하나를 100개 넘는 전문화 에이전트 무리로 바꿔준대요.

'에이전트 = 모델 + 하네스'라는 철학으로, 메모리·반복 루프·샌드박스·가드레일을 담당하는 실행 레이어예요.

최신 v3는 Claude Code 플러그인·MCP 서버·터미널 UI를 함께 제공하고, npm 월 다운로드가 1,250만을 넘는대요.

왜 중요한가: 혼자 일하던 사람에게 '전문 팀'을 붙여주는 것과 같아요. 마치 1인분 요리를 100인분 급식으로 바꾸듯, 일을 나누면 크고 복잡한 일도 해낼 수 있어요.
