AI가 1953년 수학 난제를 풀었는데, '이게 왜 중요한지'는 사람이 판단 — 그로텐디크 상수

2026-10-14

프린스턴의 프라베시 코타리 연구팀이 AI 에이전트로 1953년 난제 '그로텐디크 상수'의 범위를 좁혔다.

추론 모델이 수학을 풀고 코딩 에이전트가 검증했다. 18번째 반복에서 에이전트가 맴돌자 사람이 개입해 문제를 다시 틀어줬다.

연구진의 경고: AI는 답 찾기는 잘하지만 '어떤 결과가 중요한지' 판단은 못 한다. 발견의 지저분한 과정은 학습 데이터에 없기 때문.

왜 중요한가: 보물을 찾아내긴 했는데 금인지 그냥 반짝이는 돌인지 구분 못하는 탐험대 같은 존재.
