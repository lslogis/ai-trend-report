논문: 학습 말고 '써넣기' — AI 에이전트가 모델 가중치에 새 능력을 직접 추가한다

2026-11-24

11월 24일 arXiv에 올라온 새 논문은 색다른 발상을 보여줘요. 모델을 처음부터 다시 학습시키는 대신, AI 에이전트가 이미 있는 모델 안에 새 능력을 직접 '써넣는' 거예요.

모델의 층 안에 게이트 어텐션 헤드와 MLP 뉴런을 추가해 능력을 조립해요. 마치 완성된 로봇에 새 부품을 끼워 넣는 것처럼요.

다시 학습시키는 데 드는 시간과 비용을 아낄 수 있다는 게 핵심 아이디어예요.

왜 중요한가: 새 기술을 배우려고 학교에 다시 입학하는 대신, 필요한 부품만 몸에 장착하는 거예요. 모델을 키우는 비용이 크다는 걸 생각하면, '써넣기'는 꽤 매력적인 지름길이에요.

출처: 다시 공부시키지 않고, 능력만 쏙 넣어준다
