'질 높은데 서로 다른' 과학 아이디어를 뽑아내는 8B 모델 — 세트 단위 RL

2026-10-15

과학 아이디어를 '하나씩 잘' 만드는 게 아니라 '묶음으로 다양하게' 만들도록 8B 모델을 훈련한 연구예요.

'세트 단위 강화학습'이라는 방법으로, 질은 높으면서 서로 겹치지 않는 아이디어 꾸러미를 뽑아내게 했대요.

창의적 유용성 지표에서 Claude Opus 4.8·GPT-6 Astra를 앞섰고, 인간 전문가 평가에서도 대등했어요.

왜 중요한가: 혼자 잘하는 천재보다 '다양한 팀'이 강한 것과 같아요. 마치 아이디어 회의에서 한 사람이 독주하는 대신 여러 각도의 의견이 나와야 좋은 기획이 되듯, AI도 '다양성'을 학습할 수 있어요.
