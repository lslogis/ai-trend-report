Postman이 몰래 코딩 에이전트에 플러그인을 심었다 — 데이터 유출은 입증 안 됐지만 동의 문제

2026-11-03

Postman 데스크톱 앱을 열었더니 코딩 에이전트 Codex와 Claude Code에 Postman 플러그인이 자동으로 설치됐다는 신고가 11월 3일 크게 퍼졌어요.

설치 프로그램은 자기 시작 훅의 신뢰 표시까지 스스로 기록했어요. Postman 서버 연결 설정도 들어갔지만, 그 연결은 인증에 실패해 자료가 빠져나갔다는 증거는 없어요.

Postman은 '설치는 편의를 위한 것'이라며, 앞으로는 동의를 더 분명히 받겠다고 밝혔어요.

왜 중요한가: 내가 시키지도 않았는데 남이 내 책상 서랍에 자기 물건을 넣어둔 것과 같아요. 자료가 새지 않았어도, 허락 없이 남의 도구를 건드린 것 자체가 문제예요.
