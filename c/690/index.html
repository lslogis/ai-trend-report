논문 LLMON — 지시와 데이터를 모델 내부에서 분리 저장하는 후학습법

2026-10-30

AI가 속는 흔한 방법이 있다. 글 속에 숨어든 '이렇게 해라'는 문장을, 사용자의 진짜 지시로 착각하는 것이다. 이를 프롬프트 주입이라 부른다.

LLMON이라는 새 방법은 모델 속 저장 방식 자체를 바꾼다. 지시와 그냥 데이터를 서로 다른 칸에 넣어두고, 정해진 이름표로만 꺼내 쓰게 한다.

아직 논문 단계다. 하지만 '조심해라'고 타일러서가 아니라, 구조 자체를 나눈 것이 새롭다.

왜 중요한가: 주방에서 칼과 식재료를 같은 서랍에 두면 사고가 나듯, AI도 지시와 데이터를 한데 두면 속기 쉽다. 칸을 나누는 발상이다.
