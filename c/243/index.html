claude-mem — 에이전트가 '지난번에 하던 일'을 기억하게 해주는 영속 메모리

2026-10-10

에이전트 세션이 하는 일을 자동으로 기록·압축해서, 다음 세션에 필요한 맥락을 알아서 주입해주는 메모리 시스템이에요.

Claude Code, OpenClaw, Codex, Gemini, Copilot, OpenCode 등 거의 모든 에이전트 도구와 호환되고, MCP 검색 도구도 제공해요.

npx 한 줄로 설치되고, SQLite+벡터DB 하이브리드 검색으로 토큰을 아끼며 기억을 꺼내 써요.

왜 중요한가: "AI 비서가 매번 '처음 뵙겠습니다' 하면 곤란하잖아요 — 이건 에이전트에게 '지난 회의 내용 기억나지?'를 가능하게 해주는 비서 수첩이에요."
