GitHub Copilot Fusion 정식 출시 — 여러 모델을 골라 쓰는 코딩 에이전트 조율

2026-10-28

10월 28일 GitHub Universe에서 코딩 도우미 'Copilot Fusion'이 정식으로 나왔다.

개발자가 모델을 일일이 고르지 않아도, Fusion이 작업에 맞는 모델을 골라 조합해서 코드를 만든다.

GitHub 자체 평가로는 최고급 모델과 거의 같은 성적을, 작업당 비용은 절반, 시간은 40% 덜 들여 냈다고 한다. 여러 저장소를 넘나드는 'Copilot Projects'는 미리보기로 나왔다.

왜 중요한가: 요리사가 메뉴마다 재료를 고르듯, 코딩 AI도 일마다 맞는 모델을 고르면 값도 싸고 속도도 빨라진다 — 단, 성적은 GitHub 스스로 매긴 것이란 점은 기억해야 한다.
