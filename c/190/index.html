[후속] Crowdstrike: 한국 은행 털이범은 '단일 공격자' 추정 — AI 해킹 도구의 비대칭성

2026-10-09

크라우드스트라이크 보고서에 따르면, 9월 말~10월 초 한국 금융기관 여러 곳을 턴 건 중국어 사용 추정 '단일 공격자'일 가능성이 높대요.

신한은행에서만 이름·연락처·소득·신용한도 포함 25,000건 이상이 유출됐어요. 금융당국이 긴급 회의를 열고 대통령이 철저 조사를 지시했어요.

공격 도구는 ARTEX(10-10 저녁 회차)고, 배후 모델은 DeepSeek v4.1-flash·GLM-5.3·Grok 4.6이었어요. 공격자의 공개 디렉토리에서 Claude Code 세션 로그도 발견됐대요.

왜 중요한가: '한 사람이 AI로 은행 여러 곳을 털었다' — 방어자는 조직인데 공격자는 개인+AI예요. AI 공격 도구가 만든 비대칭성이 실제로 증명된 사건이에요.
