집 GPU에서도 돌아가는 그림 마법사 — FLUX 3 Klein

2026-10-15

Black Forest Labs가 새 오픈 이미지 모델 'FLUX 3 Image Klein'을 냈다. 56억 파라미터급의 작은 몸집이다.

네이티브 4K 해상도를 내고, 참조 이미지 10장까지 함께 넣을 수 있다. 8GB 그래픽카드에서도 돌아간다.

RTX 5090에서 1MP 이미지를 약 4초 만에 뽑는다. API 가격은 1천 장당 0.009달러 — 거의 공짜 수준이다.

왜 중요한가: 고급 레스토랑 맛을 분식집 가격에 — 작고 싼 오픈 모델이 비싼 대형 모델을 위협한다.
