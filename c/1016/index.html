AWS, 자가호스팅 LLM용 분산 KV 캐싱 에이전트 스킬 공개 — 비용·대기시간 줄이기

2026-11-21

AWS가 Agent Toolkit용 새 스킬을 공개했다. 코딩 에이전트가 자가호스팅 LLM에 분산 KV 캐싱을 깔도록 돕는다.

긴 대화를 GPU 서버마다 따로 계산하던 낭비를, 공유 캐시 하나로 줄인다. 다른 서버가 이어받아도 처음부터 다시 계산하지 않는다.

AWS 주장으로는 추론 비용 최대 40% 절감, 첫 토큰까지 시간 최대 80% 단축이다.

왜 중요한가: 요리할 때마다 양파를 새로 다지는 대신, 다져놓은 양파를 모두가 쓰는 공용 냉장고에 넣어두는 셈이다.
