GitHub Copilot, 기기 넘나드는 클라우드 세션 + 26개 서비스 '한 번 연결' 공개 프리뷰

2026-11-02

GitHub이 11월 2일 전해진 소식에서, Copilot 작업을 클라우드에 이어서 하는 기능을 발표했다.

컴퓨터·휴대폰·채팅 앱을 바꿔도, 하던 코딩 작업과 맥락이 그대로 이어진다. 다시 세팅할 필요가 없다.

슬랙·피그마·노션 등 26개 서비스를 한 번만 연결해 두면, 어느 화면에서든 같은 연결을 쓰는 기능도 공개 프리뷰로 나왔다. 다만 연결이 한곳에 모이는 만큼 보안 점검이 중요하다.

왜 중요한가: 책상·소파·카페를 옮겨 다녀도 책갈피가 그대로인 책처럼 — 어디서 열어도 하던 작업이 이어지는 코딩 도우미가 됐다는 뜻이다.
