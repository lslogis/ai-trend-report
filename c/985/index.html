논문 'Game2Player' — 게임 만드는 AI와 게임하는 AI가 함께 자라다

2026-11-18

11월 18일 공개된 논문 'Game2Player'는 게임 AI를 키우는 새 방법을 제안했어요.

'빌더' AI가 웹 게임을 고쳐서 연습 문제를 만들고, '플레이어' AI가 그 게임을 하면서 문제를 보고하면 빌더가 다시 고쳐요.

이렇게 만든 게임 568개·과제 3,436개로 학습한 AI는 게임 진행률이 14.3%에서 31.2%로 두 배 넘게 올랐어요.

왜 중요한가: 선생님 AI가 문제를 만들고 학생 AI가 풀면서, 둘 다 같이 똑똑해지는 거예요. 마치 문제집 만드는 선생님과 푸는 학생이 서로를 키워주는 것 같아요.
