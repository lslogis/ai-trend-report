2026-11-16

텐센트가 코딩 에이전트들을 조율하는 도구 'LoopForge'를 공개했어요. GitHub 일간 트렌딩에 올랐어요.

CodeBuddy·Codex·Claude Code를 스크립트와 사람 승인 절차로 묶어 함께 일하게 해요.

내 컴퓨터·내 서버에서 직접 돌리는 셀프호스팅 방식이에요.

왜 중요한가: 혼자 일하는 요리사 여러 명을 주방장이 메뉴와 순서대로 지휘하는 것과 같아요. AI 코딩 도구들도 이제 '팀플레이'를 배우고 있어요.
