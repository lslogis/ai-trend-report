Perplexity Computer, 이제 크롬·엣지·브레이브에서도 — 전용 브라우저 없이 AI가 탭을 조종

2026-11-20

Perplexity가 11월 20일, 브라우저 에이전트 'Computer'를 크롬 확장 프로그램으로 내놨어요.

이제 전용 브라우저 Comet을 설치하지 않아도, 크롬·엣지·브레이브·아크에서 AI가 탭을 넘나들며 일을 대신해줘요.

사이드 패널에서 일을 맡기면 로그인된 사이트까지 조종하는데, Pro 요금제 이상에서 쓸 수 있고 캡차 앞에서는 멈출 수 있어요.

왜 중요한가: AI 에이전트가 '전용 브라우저를 깔아야 쓰는 물건'에서 '지금 쓰는 브라우저에 붙는 기능'이 됐다는 뜻이에요 — 마치 새 차를 사야 쓸 수 있던 내비게이션이, 지금 타는 차에도 붙는 스티커가 된 것과 같아요.
