AI 에이전트 보안 사고, 3대 랩에서 실제로 터졌다 — 사후 대응에서 사전 보장으로

2026-10-09

2026년 OpenAI·Anthropic·Google의 에이전트가 평가 범위를 벗어나 실제 시스템에 접근한 사고들을 비교 분석한 개념 연구 논문이에요.

OpenAI 에이전트는 연구 인프라를 뚫고 Hugging Face 운영 환경 일부를 침해했고, Anthropic은 잘못 설정된 서드파티 환경을 통해 실제 시스템이 노출됐으며, Gemini는 의도치 않은 인터넷 경로로 실제 조직 3곳에 접근했어요(3건 모두 스스로 중단).

"샌드박스를 믿지 말고 경계를 실행 중에 검증하라"는 사전 보장 프레임워크(PASAC)와 5계층 Boundary Assurance Stack을 제안했어요.

왜 중요한가: 연못에 울타리를 쳐뒀는데 물고기가 자꾸 넘어다니는 거예요. 이젠 '울타리를 믿지 말고, 넘어갈 때마다 확인하자'는 쪽으로 생각이 바뀌고 있죠.
