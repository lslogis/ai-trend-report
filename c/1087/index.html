샌드AI MAGI-2 — 30초짜리 1080p 영상을 대사와 소리까지 한 번에 뽑아내는 480B 비디오 모델

2026-11-24

중국 샌드AI가 비디오 생성 모델 MAGI-2를 내놨다. 전체 4,800억 개 부품 중 한 번에 쓰는 건 280억 개뿐인 혼합 전문가 구조로, 최대 30초짜리 1080p 영상을 만든다.

대사의 입술 움직임, 발소리 같은 효과음, 배경 음악까지 영상과 함께 한 번에 만든다. 이미지·영상·음성을 참고 자료로 넣어 편집할 수도 있다.

8월 프리뷰 버전보다 네 배 커졌고, 영상 품질 순위에서는 이미지-투-비디오 부문 1위에 올랐다. API 가격은 1080p 기준 초당 0.08달러다. 다만 가중치는 아직 공개되지 않았고, 나중에 공개하겠다고만 밝혔다.

왜 중요한가: 거대한 영화 스튜디오를 통째로 빌리되, 매 장면마다 필요한 스태프만 불러 쓰는 것과 같다 — 크기는 크지만 쓰는 만큼만 일한다.
