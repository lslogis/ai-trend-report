AI 에이전트용 격리 샌드박스 — agent-microvm

2026-10-21

AWS Lambda MicroVM(Firecracker) 기반의 일회용 격리 샌드박스를 다루는 Python SDK·CLI·MCP 서버다.

vmnest CLI로 3초 만에 부팅하고 일시정지·재개가 가능하다.

Claude·Cursor 등에서 네이티브 도구처럼 호출할 수 있어, 에이전트가 만든 미검증 코드를 안전하게 실행하기에 적합하다. 스타 46.

왜 중요한가: 에이전트에게 '실험실 방호복'을 입혀주는 것이다. 무슨 코드를 짜내든 유리 상자 안에서만 놀게 하니 안심이다.
