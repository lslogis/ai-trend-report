AWS, 오픈웨이트 결정 모델 'Strands Decider v2' 5종 공개 — 글을 안 쓰고 확률만 매긴다

2026-11-23

AWS가 11월 23일 오픈웨이트 결정 모델 'Strands Decider v2' 5종을 공개했어요. Gemma 4를 바탕으로 만들었고 Apache 2.0 라이선스라 누구나 내려받아 쓸 수 있어요.

이 모델은 글을 만들지 않아요. 주어진 선택지마다 '이게 맞을 확률'을 매길 뿐이에요. 에이전트가 다음에 뭘 할지 고를 때 쓰는 '작은 심판'이에요.

아마존 내부 티켓 시스템에서는 Claude Sonnet 4.6 대신 이 모델을 써서 라벨 붙이는 비용이 98% 줄고, 속도도 78% 빨라졌다고 해요.

왜 중요한가: 에이전트에게 매번 비싼 대형 모델을 부르는 건, 물 한 잔 마시자고 호텔 요리사를 부르는 것과 같아요. 확률만 매기는 작은 모델이 일상 결정을 대신 맡으면, 비용은 줄고 속도는 빨라져요.
