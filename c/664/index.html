OpenAI, ChatGPT Pro·Business에 월 최대 $500 API 크레딧

2026-10-28

OpenAI가 10월 28일 ChatGPT Pro·Business 구독자에게 매달 API 크레딧을 주기 시작했다.

Pro는 요금제에 따라 월 100달러, 200달러, 500달러를 받는다. Business는 좌석당 표준 20달러·프리미엄 100달러를 합쳐 워크스페이스당 월 500달러가 상한이다.

조건은 가입 7일 이상, 같은 이메일, API 조직 소유다. 안 쓴 크레딧은 다음 달로 안 넘어가고, 채팅 사용량 한도가 늘어나는 것도 아니다.

왜 중요한가: 헬스장 회원권에 옆집 공방 무료 이용권 몇 장이 딸려온 셈이다. 다만 이달 안에 안 쓰면 사라진다.
