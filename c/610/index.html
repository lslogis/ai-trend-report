구글, '코끼리-금붕어' 설계 우선 코딩 플러그인 오픈소스 공개

2026-10-26

구글이 10월 26일 '코끼리-금붕어' 코딩 플러그인 EGM을 GitHub에 오픈소스로 공개했어요.

바로 코드를 짜지 않고, '코끼리'가 설계 논의를 설계 문서로 만든 뒤, 아무것도 모르는 '금붕어' 검토자가 허점을 지적해요.

사람이 승인해야 코드가 시작되고, 구글 내부 수천 명 엔지니어가 이미 쓴다고 해요.

왜 중요한가: 벽돌 한 장 쌓기 전에 설계도를 그리고, 모르는 사람이 허점을 찔러보는 격 — 시작은 느리지만 나중에 허무는 벽이 훨씬 적어요.
