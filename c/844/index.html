메타, 에이전트 전용 초경량 모델 뮤즈 엠버 출시 — 입력 100만 토큰에 10센트

2026-11-09

메타가 에이전트 전용 초경량 모델 뮤즈 엠버를 11월 9일 내놨다.

도구 호출, 코딩 조각, 문서 정리처럼 에이전트가 하루 종일 반복하는 일을 맡는다.

입력 100만 토큰에 10센트로, 하이쿠·루나보다 싸면서도 똑똑하다는 평가다.

왜 중요한가: 마치 편의점 알바생 — 비싼 셰프가 아니라, 매일 반복되는 일을 빠르고 싸게 해치우는 일꾼이다.
