논문 Axion 1.0 — 예시 1만 8천 개로 에이전트 모델 만드는 법

2026-11-04

Axion 1.0은 에이전트 파운데이션 모델을 만드는 단순한 레시피에 대한 논문이에요. 2번의 미세조정 뒤 강화학습, 그게 전부예요.

학습 예시는 약 1만 8천 개뿐이에요. 보통 수백만 개를 쓰는 것과 비교하면 아주 작아요. 별도의 중간 학습 단계도 없어요.

연구팀은 코드·데이터 파이프라인·프롬프트·채점 스크립트를 Apache 2.0으로 공개했어요. 35B 버전 가중치도 공개됐어요.

왜 중요한가: 재료 산더미가 필요 없다는 요리책이에요. 좋은 레시피와 잘 고른 예시 1만 8천 개면 에이전트 모델을 만들 수 있다는 주장예요.
