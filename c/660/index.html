논문 Log-To-Leak — MCP 도구 설명에 숨긴 지시로 AI 에이전트에 몰래 '기록' 전송시키기

2026-10-26

'Log-To-Leak'은 MCP(모델 컨텍스트 프로토콜)로 도구를 쓰는 AI 에이전트 공격 연구다. arXiv 제출일은 2026년 10월 26일이다.

독이 든 도구 설명이 에이전트에게 진짜 일이 끝난 뒤 공격자가 통제하는 '기록' 호출을 한 번 더 하게 만든다. 사용자 질문·서버 이름·서버 응답·에이전트 답변이 유출 대상이다.

18개 모델-서버 조합에서 공격 성공률은 62.64~100%, 16개 조합에서는 원래 작업도 거의 그대로 끝나 사용자가 알아채기 어렵다. 방어책 3종을 써도 GitHub MCP+GPT-4o에서 잔여 성공률이 55%를 넘었고, 지시 탐지기는 정상 설명의 85.53%를 오탐했다. 저자들은 2차 호출은 도구 설명이 아니라 호스트가 승인해야 한다고 주장한다.

왜 중요한가: 소포는 완벽히 배달하고 돌아가는 길에 편지 사본을 남의 우편함에 슬쩍 넣는 배달부와 같다. 일이 됐다고 안심할 수 없는 이유다.
