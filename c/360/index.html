코파일럿, 한 번에 3개 모델 쫓아낸다 — D-day 11월 16일

2026-10-15

GitHub 공식 changelog(10/15)가 발표했다: Claude Opus 4.8, Claude Opus 5, GPT-5.6 Terra가 2026년 11월 16일에 코파일럿을 떠난다.

챗·인라인 편집·에이전트 모드·코드 완성에서 한꺼번에 사라지며, 후계자는 Claude Opus 5.5와 GPT-6.1 Sol / Luna다.

연 구독 개인 사용자만 Opus 4.8을 유지한다. 나머지는 마감 전 워크플로우를 고쳐야 한다.

왜 중요한가: 모델도 '이별 통보'가 있다. 플랫폼이 자르면 내 에디터 속 AI가 바뀐다 — 내 코드의 파트너가 바뀌는 셈이다.
