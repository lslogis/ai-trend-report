센스타임 RoboRSI-27B — 로봇팔이 '몸으로 익힌 동작'과 '코드로 계산'을 스스로 골라 쓴다

2026-11-25

센스타임이 로봇팔용 비전-언어 모델 SenseNova-RoboRSI-27B 정식 버전을 Apache 2.0 라이선스로 공개했다. 270억 개 부품짜리 오픈 가중치 모델이다.

이 모델의 특기는 선택이다. 몸으로 익힌 동작 정책(VLA)으로 움직일지, 직접 코드를 짜서 집게 위치를 계산할지, 상황에 따라 스스로 고른다.

로봇 평가 RoboDojo에서 34.7점을 받아 GPT-6 Astra(27.6)보다 높았고, Opus 5.5(40.7)보다는 낮았다. 시뮬레이션에서만 학습했는데도 같은 가중치가 실제 로봇팔 두 대에서 그대로 동작했다.

왜 중요한가: 로봇에게 '감으로 움직이는 손'과 '자자로 재는 손'을 둘 다 주고, 어느 손이 나은지 스스로 고르게 한 것이다 — 마치 요리사가 손맛과 계량컵을 상황에 따라 바꿔 쓰는 것처럼.

출처: 27B 오픈 로봇 모델, 시뮬레이션만으로 배워 실제 로봇팔에서도 동작
