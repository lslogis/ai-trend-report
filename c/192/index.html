OpenAI, 미발표 모델 'gpt-rosalind-discovery' 문서에 유출

2026-10-10

OpenAI API 가격 페이지의 'Life sciences models' 섹션에 'gpt-rosalind-discovery'라는 미발표 모델이 조용히 추가된 게 10월 10일 포착됐어요. 공식 블로그나 시스템 카드는 없어요.

가격은 research와 동일해요: 입력 $5/1M, 출력 $25/1M 토큰. 승인된 기관만 접근하는 trusted-access 프로그램 경유예요.

GPT-Rosalind-5.5는 GPT-5.5 기반 바이오/신약 프론티어 추론 모델이에요. 'discovery' 변형은 타겟 발굴·분자 설계 특화일 가능성이 있어요 — 공식 미확인.

왜 중요한가: AI 업계 특유의 정보전이에요. OpenAI는 가격 페이지에 먼저 올려두고 나중에 정식 발표하는 패턴을 자주 써요.
