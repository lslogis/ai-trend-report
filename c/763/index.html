문샷 Kimi K3.1 Pro 가중치 공개 — 2.8조 파라미터, 1M 컨텍스트

2026-11-04

문샷 AI가 약속을 지켰어요. 11월 4일, Kimi K3.1 Pro의 전체 가중치를 Hugging Face에 공개했습니다.

전체 부품은 2조 8천억 개, 하지만 한 번에 일하는 부품은 1,040억 개뿐이에요. 한 번에 100만 토큰까지 읽을 수 있습니다.

라이선스는 문샷 전용 조건이 붙어요. 웬만한 사람은 자유롭게 쓸 수 있고, 아주 큰 API 사업자나 초대형 제품에만 추가 조건이 붙습니다.

왜 중요한가: 최상급 모델을 이제 직접 내려받아 돌릴 수 있게 됐다는 뜻이에요. 마치 스타 셰프의 대표 요리 레시피가 공개된 것과 같아요.
